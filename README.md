# Web-Practice

Exercícios de HTML e CSS da disciplina Introdução às Tecnologias Web
(Engenharia de Software - PUC-Campinas). Cada arquivo corresponde a uma aula
ou a uma tarefa entregue.

## aulas/

- `aula1-html-basico.html` — estrutura básica da página: títulos, parágrafos,
  listas não ordenadas, ordenadas e aninhadas, tabelas com `colspan` e
  `rowspan`, e links por âncora. Sem CSS.
- `aula2-css-basico.html` + `.css` — primeira aula de CSS: seletores por tag,
  class e id, `width`/`height`, box model e cards.
- `aula3-display-flexbox.html` + `.css` — `display` block, inline e
  inline-block; flexbox com `flex-direction`, `justify-content`,
  `align-items`, `gap` e `flex-wrap`.
- `aula4-bootstrap-responsivo.html` + `.css` — Bootstrap 5 via CDN: grid
  responsivo, cards, formulário e tabela, com CSS próprio por cima.
- `aula4-formularios.html` + `.css` — tipos de input do HTML5, `select`,
  `optgroup`, `datalist`, `fieldset` e layout do formulário em duas colunas.

## tarefas/

- `tarefa1-guia-viagens.html` — guia de viagens pelo Brasil: listas aninhadas
  em três níveis, tabela com `colspan`/`rowspan` e navegação por âncoras.
  Só HTML, sem folha de estilo.
- `tarefa2-landing-page.html` + `.css` — landing page de uma escola de cursos,
  montada com flexbox.
- `curriculo.html` + `.css` — currículo pessoal em HTML e CSS.

## Como abrir

Basta abrir qualquer arquivo `.html` no navegador — não há build nem
dependência para instalar.

O único que precisa de internet é o `aula4-bootstrap-responsivo.html`, que
carrega o Bootstrap por CDN. Sem conexão, ele abre sem a estilização do
framework.
