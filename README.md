# Web-Practice

Exercícios da disciplina Introdução às Tecnologias Web (Engenharia de
Software - PUC-Campinas - 2° Semestre).

## Estrutura

- `aulas/` — conteúdo visto em sala: os exemplos e exercícios de cada aula.
- `tarefas/` — parte prática: as tarefas entregues ao longo da disciplina.

## Nomes dos arquivos

Cada exercício segue o padrão `aulaN-tema` ou `tarefaN-tema`, onde `N` é o
número da aula ou da tarefa. Quando o exercício tem CSS ou JavaScript, esses
arquivos levam o mesmo nome do HTML:

```
tarefa4-stayeasy-hotel.html
tarefa4-stayeasy-hotel.css
tarefa4-stayeasy-hotel.js
```

Uma mesma aula pode ter mais de um exercício, cada um com seu próprio tema
(por exemplo, `aula4-formularios` e `aula4-bootstrap-responsivo`).

## Como abrir

Basta abrir o arquivo `.html` no navegador — não há build nem dependência
para instalar.

Alguns exercícios carregam bibliotecas por CDN (como o Bootstrap). Sem
internet, eles abrem sem a estilização da biblioteca.
