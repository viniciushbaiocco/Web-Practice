Aula 01 - HTML Básico

Primeira aula de HTML, sem CSS. O objetivo é montar a estrutura da página usando apenas as marcações básicas: títulos, parágrafos, listas, tabelas e links.

Navegação

  • Listas
  • Tabelas
  • Links

Listas

Uma lista não ordenada marca itens sem sequência definida:

  • Introdução às Tecnologias Web
  • Algoritmos e Programação em C
  • Banco de Dados
  • Engenharia de Requisitos

Uma lista pode conter outra lista dentro dela:

  • Programação
    • Algoritmos e Programação em C
    • Introdução às Tecnologias Web
  • Dados
    • Banco de Dados
    • Modelagem de Dados

Uma lista ordenada é usada quando a sequência importa:

  1. Criar o arquivo com a extensão .html
  2. Escrever o DOCTYPE e a tag html
  3. Preencher o head com o charset e o title
  4. Montar o conteúdo dentro do body
  5. Abrir o arquivo no navegador para conferir
